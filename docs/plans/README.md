# Implementation Plans

This directory is the canonical, version-controlled project memory for generated implementation plans.

Save each approved plan before implementation using `YYYY-MM-DD-short-kebab-case-title.md`. Add each plan to `INDEX.md` with its date, title, status, and a relative Markdown link. Include the goal, implementation changes, test scenarios, and explicit assumptions. Do not include PAN, secrets, credentials, or unnecessary cardholder data.

Do not edit an approved plan to represent a material change. Create a new superseding plan instead, link to the prior plan, and record the relationship in `DEVELOPMENT_LOG.md`.
